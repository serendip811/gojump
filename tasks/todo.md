## KB 공급 실데이터 상태 집계 수정

- [x] KB 공급 반영 시 실데이터 개수 증가

- [x] 국토부 일시 장애 시 완전한 월 캐시 폴백 적용

### Review

- `with_live_kb_supply`도 서울시 공급 폴백과 동일하게 `liveIndicatorCount`, `dataMode`, 신뢰도와 반영 개수 라벨을 갱신한다.
- 네 개 실지표 상태에서 KB 공급을 반영하면 5개 `partialLive`, 이어 확산도를 반영하면 6개 `live`가 되는 회귀 테스트를 추가했다.
- 국토부 최신 월 재조회가 실패해도 서울 25개 구 수집 완료가 확인된 캐시는 사용할 수 있게 했다. 불완전 캐시라면 예외를 유지해 배포를 막는다.
- Python 테스트 55개가 통과했다. GitHub Pages 재배포 응답 확인은 푸시 후 진행한다.
- Actions 재배포가 성공했고 공개 JSON에서 `dataMode=live`, `liveIndicatorCount=6`, 종합점수 64를 확인했다.

## 비인기 확산도 재편입 변형 백테스트

- [x] 절대 수준·수준 증폭·고점 대비 둔화 파생점수 정의
- [x] 수준/둔화 조합과 3%·5%·10% 가중치 전수 비교
- [x] 기존 5지표 대비 6·12개월 성능과 경보 시점 비교
- [x] 현재 종합점수 영향 및 과최적화 위험 평가
- [x] 권고 편입안과 회귀 테스트 문서화

### Review

- 확산 원점수, 중립 50에서 거리를 2배로 확대한 수준점수, 직전 6개월 최고점 대비 하락을 변환한 둔화점수를 만들었다. 수준/둔화 비중 25:75·40:60·60:40과 단독형을 3%·5%·10%로 비교했다.
- 기존 점수를 비례 축소하는 `가중평균`과, 확산 파생점수가 중립 50을 넘는 부분만 더하는 `보너스` 방식까지 총 36개 조합을 동일한 80점 경계에서 평가했다.
- 기준 5지표는 12개월 5% 하락 정밀도 92.3%·재현율 100%, 6개월 정밀도 46.2%·재현율 100%, 최초 경보 2021년 12월(고점 7개월 전)이었다.
- 3%·5% 가중평균은 대부분 기준 성능과 같았지만 점수가 낮은 확산도가 기존 종합점수를 깎는 문제가 있었다. 10% 원점수·수준 직접 편입은 12개월 재현율을 91.7%, 6개월 재현율을 83.3%로 낮췄다.
- 보너스 방식의 수준 60%·둔화 40%, 강도 5%는 기준 성능과 경보 시점을 모두 그대로 유지했다. 반면 둔화를 60~100%로 높이면 경보가 1회 늘어 12개월 정밀도가 85.7%, 6개월 정밀도가 42.9%로 낮아졌다.
- 권고안은 `수준 60% + 둔화 40%` 파생점수가 50을 넘는 부분의 5%만 보너스로 더하는 방식이다. 기존 점수를 낮추지 않고 최대 영향은 +2.5점이며, 최신 백테스트 월은 66→67점으로 1점 상승한다.
